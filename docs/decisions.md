| 7 | 2026-10-16 | **How relocation is proven.** `-D SHIFT=&100` assembles the game a page lower (`&0D00`) and moves each bank's contents a page higher; `-D SHIFT_END=1` is the control, the same padding where it moves nothing, so both discs load in the same time. Moving by whole pages keeps every page crossing, so a correct relocation runs cycle for cycle like the control - even with the game's random numbers coming from a VIA timer. `tools/lockstep.mjs` compares screen RAM every frame and the rendered frame every tenth; `tools/tracediff.mjs` stops both at the first instruction or screen/column-buffer write that differs. Measured 2026-10-16 (jsbeeb 2.5.0): 30,000 frames identical with scripted play and `DEBUG_LIVES`. | `src/main.6502`, `tools/` |
